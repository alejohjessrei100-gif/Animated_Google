## Series hooks (formats that make people binge)
- **"The [X] that broke [Y]"** weekly: same opening sting, same character style, a different scam each week. It trains the algorithm and the viewer.
- **Part-2 bait without a CTA:** end on the twist, not "part 2". Series continuity comes from a recurring narrator line, e.g. "You see," on screen in the first second.
- **Loop endings:** make the last image match the first shot (same object, same angle). `hook_check.py` scores it (loop match ≥ 0.80). Loops add free rewatches, which the Shorts algorithm counts.
