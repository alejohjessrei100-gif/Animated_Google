# OddTilt Low-Poly Shorts (30fps)

Generate production-ready **28–34 second (840–1,020 frame @ 30fps)** YouTube Shorts that replicate **Odd Tilt's** exact script structure, comedic pacing, and mechanic-first staging—translated into a clean **low-poly 3D** aesthetic.

Before writing any script or shot list, read `references/style_bible.md` for the full timing grid, shading, camera, caption, and audio rules. Use `references/example_script_umbrella.md` as the reference benchmark for beat density and formatting.

---

## Workflow

### 1. Ask About the Main Character (If Not Already Provided)
- **Before writing the script or beat sheet**, check whether the user has already described their main character.
- If they haven't, **ask them what they want their main character to look like** (e.g., body shape/proportions, outfit, colors, hair/hat, or signature accessory) so the character fits their low-poly channel identity.
- Keep the question brief and specific; once they answer (or if they tell you to pick one), carry that exact character description consistently through every shot of the beat sheet (including the slapstick/wheelchair gag if used).

### 2. Lock the Premise & Title
- Use the second-person title hook: **`How you invented [the everyday object]!`**
- Pick an absurd, relatable, or slightly unhinged inciting problem that naturally leads to the invention's real-world engineering steps.

### 3. Write the Voiceover Script (Zero Dead Air)
Follow the strict 5-stage escalation skeleton in **second-person present tense (`"you"`)**:
1. **Inciting Problem (`0:00–0:03` | `F000–F090`):** Drop straight into the problem on Frame `0`. Zero intro, zero backstory.
2. **Naive Fix (`0:03–0:06` | `F090–F180`):** `"So you [obvious brute-force fix]."`
3. **Escalation Loop (`4–5×`, `~4–5s` / `120–150 frames` each):**
   - **Complication:** `"But..."` or `"Except..."` — alternate between real mechanical bottlenecks and sudden slapstick consequences (e.g., breaking your spine, getting kicked out).
   - **Engineering Step:** `"So you [add specific real-world mechanism]."`
   - **Micro-Praise:** Every 1–2 loops, drop a deadpan `"Clever!"` or `"Genius!"` right before undercutting it with the next `"Except..."`.
4. **Callback Punchline (Final `2–3s` | `60–90 frames`):** Close with a deadpan callback to the opening gag (`"Now you can [original goal]—[comedic twist]."`) rather than `"Congratulations, you've invented X."`

### 4. Build the Frame-by-Frame 30fps Beat Sheet
Deliver a table mapping every beat with:
- **Time & Frame Range** (`F000–F090`, etc. @ `30fps`, `1080×1920` `9:16`).
- **VO Line** (trimmed so there is zero dead air between clauses).
- **Low-Poly Visual & Camera** (1-frame hard cuts on `"But..."` / `"Except..."`, alternating 3/4 establishing shots and tight mechanic close-ups, snappy `6–10 frame` ease-out moves, never holding a static angle > `90 frames`, featuring the user's chosen main character).
- **Part Highlight / VFX** (5-frame `0 → 1.08 → 1.0` pop-in, `8–12 frame` emissive `#38E54D` green upgrade flash or `#FF3B30` red impact flash, `25–35%` alpha X-ray shell for internal parts, and simple low-poly geometric metaphors for wind/sound/rain).
- **Captions** (`2–4 words` per chunk, centered above the lower-third safe zone, ALL-CAPS on shock words and `"CLEVER!"` / `"GENIUS!"`).
- **SFX Cue** (frame-accurate foley and slapstick hits).

---

## Non-Negotiable Constraints
- **Never skip asking about the main character** if the user hasn't specified one yet.
- **Never exceed `45 seconds` (`1,350 frames`)**; target `28–34 seconds`.
- **Never use realistic/MakeHuman visuals**—every character, prop, and particle must use flat-shaded low-poly geometry with desaturated backgrounds and saturated hero props.
- **Never put full sentences in on-screen captions**; keep chunks to `2–4 words`.
- **Every new mechanical part** must be visually isolated with an emissive flash or X-ray cutaway on the exact frame it is mentioned in the VO.
